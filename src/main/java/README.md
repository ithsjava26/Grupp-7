#  🧟The Last Shift
A Java console based survival horror game.

## 👾Running the Game
To run the game, you need to have Java JDK 27 or higher installed on your computer.
The project is developed using Java 27 

## 🎮Game Overview: 
The Last Shift is a Java-based console survival horror game set in a city overwhelmed by a zombie outbreak. 
The player must navigate through dangerous locations, explore abandoned rooms, collect essential supplies, and
survive encounters with hostile enemies while trying to find their way home.
